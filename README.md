# esp-modelbouw

Bestanden voor automatische software-updates van het mini-billboard (2,2-inch, wifi).

**Huidige versie: 2.7** — zie `CHANGELOG.md`.

| Bestand | Wat |
|---|---|
| `billboard.bin` | De nieuwste software. Het bordje haalt die hier zelf op. |
| `herstel.bin` | Vaste versie om op terug te vallen (herstelmodus). |
| `billboard_eerste_installatie.bin` | Volledig bestand voor de allereerste keer flashen (4 MB). |

Niet hernoemen, verplaatsen of verwijderen.
